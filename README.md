### 🚀 Featured Project

#### 🤖 AdVision AI — Intelligent Advertising System
*Senior Design Project · Jordan University of Science and Technology · 2025–2026*

A full-stack AI-powered advertising platform that detects real-time audience demographics using computer vision, dynamically displaying targeted content through a modern web dashboard.

| Layer | Technologies Used |
| :--- | :--- |
| 🧠 **AI Engine** | Python · OpenCV · Demographics Detection |
| 🌐 **Backend** | Flask · REST API · SQLite |
| 🎨 **Frontend** | HTML5 · CSS3 · JavaScript |
| 📊 **Dashboard** | Live Analytics · Ad Management · HUD-Style UI |

**Key Features:**
- 🎯 Real-time audience demographic detection via computer vision
- 📱 Full CRUD ad management (Add / Edit / Delete)
- 📊 Live analytics charts and status monitoring
- 🔗 REST API connecting AI engine with web dashboard
